# Great House Farm · Project Office

The Project Office webapp for the Williams–Buckler family’s research into Great House Farm / Tŷ Mawr, Llandough-juxta-Penarth, its records, land and title history, and related family and public history.

This repository contains the Project Office interface, workstream plans, milestones, dependencies, risks and public-safe progress views.

**Systems of record:** HubSpot holds private tasks and correspondence follow-ups; Gmail holds original correspondence; the central evidence catalogue holds source-linked records; Hive coordinates agents and reviews; this app presents the programme. The Project Office is not a second task database or an evidence source.

The programme and its automation plan are set out in [MASTERPLAN.md](MASTERPLAN.md). All conclusions remain subject to the evidence and source references; disputed propositions are not presented as findings of a court.
